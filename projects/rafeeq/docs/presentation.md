# Eight-minute capstone outline

1. **Problem and user — 1 minute:** citizens need bilingual, grounded municipal guidance across five permit types.
2. **Live demo — 2 minutes:** ask a fee question, verify a synthetic applicant, find an inspection slot,
   propose it, show the approval card, confirm, and show the persisted booking.
3. **Design — 2 minutes:** diagram; why one agent; MCP boundary; retrieval; public memory;
   backend identity enforcement; citizen versus finance authorization; budgets and traces.
4. **Evaluation — 2 minutes:** replace this section with actual live A/B results, root causes, examples
   of improvements/regressions, and trial counts. Label the separate offline retrieval benchmark accurately.
5. **Security — 1 minute:** show attack text, blocked tool request, enforced defence and residual risks.

Before presenting: set team names, pin an available model, run 20 live tasks on A and B, manually review graders,
record a short backup video, test a clean clone, and export reviewed synthetic-only CSVs and slides.
Be prepared to explain why the current implementation is a capstone service rather than a production deployment.
